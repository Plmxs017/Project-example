# 需求与验收标准

本文件把《背景与要求.doc》转成可检查的验收项。实现细节见 `readme.md`，仿真规则见 `backend/sim/`。

## 一、车辆能力

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| V1 | 能够自检 | 手动 / 火情 / 故障均可触发；自检有进行中进度、6 项状态和最终结论；页面可见 |
| V2 | 水量 < 10% 前往最近补水站 | 待命或自检发现低水量时自动调度；目标站按路网行驶距离取最近 |
| V3 | 功能故障前往最近维修站 | 故障会体现在自检结果；车辆自动规划到最近维修站并计时修复 |
| V4 | 机械臂移开障碍 | 行驶中检测前方路障，停车、机械臂动画、移除后继续原任务 |
| V5 | 灭火时水量可低于 10%，耗尽才补水 | 喷水过程中不因低于 10% 中断；水量为 0 时保留火情并去补水 |
| V6 | 遇行人自主降速 | 前方行人进入锥形检测区后降速，近距离停车，行人离开后恢复 |
| V7 | 检测到火情立刻自检 | 新火情生成即进入自检；通过后出发，失败则先补水 / 维修 |
| V8 | 消防车视觉突出 | 放大消防车并增加高对比度定位环、光晕、红蓝警灯和「消防车」标签；仍使用系统 emoji，不自定义角色形象 |

## 二、世界与交通

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| W1 | 交通地图化 | 双向道路、车道线、人行道、斑马线、信号灯、建筑、树木、服务站 |
| W2 | 车辆连续移动 | 位置为浮点坐标，按速度与转向角速度推进，不按格子跳 |
| W3 | 行人连续移动 | 随机起点 / 终点，沿人行图移动，斑马线过街 |
| W4 | 行人遵守交通规则 | **严格沿路边人行道走，过街只走斑马线、不横穿马路**；红灯在路口等待，绿灯通过 |
| W5 | 随机生成行人 | 启动生成 10 名，抵达终点后随机选择新目的地 |
| W6 | 常驻的私家车 | 路网常驻 2 辆，跑完一段自动换路线继续跑；按现实行车规则：跟车保距、路口一次一辆先到先走、**会车不越线、见行人减速停车**；遇消防车一律靠边停车让行（允许路边斜停），平时停稳时车头自动摆正、不横在路面；**只靠刹车保持车距，不推挤、不瞬移，不撞车也不撞行人** |
| W7 | 路口拥堵疏通 | 路口连续堵住 3 秒触发三步处理：**行人自行寻找可行路线绕开该路口 → 小车靠边腾出车道 → 消防车需要经过时优先通过（不强制派车）**；小车全程不许开进建筑 |
| W8 | 消防车被堵 / 故障 | 消防车被小车堵住 3 秒或带故障遇车时：**附近小车朝消防车的反方向驶离**（暂时不再等它），随后消防车返回维修站维修 |

## 三、AI 能力（新增）

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| A1 | 一键规划最优路线 | 点击按钮后返回访问顺序、总里程、每段距离；有火情时覆盖全部火点，无火情时转为全域巡检 |
| A2 | 算法可解释 | 同时给出「原始顺序 / 最近邻 / 2-opt / 精确 DP」的里程对比，并标明所用算法与节省百分比 |
| A3 | 路线可视化 | 地图画出靠右车道的折线、编号站点，执行时高亮当前站并把已完成站点打勾 |
| A4 | 一键执行 | 车辆按 AI 顺序逐站前往，到火点自动灭火；低水量 / 故障 / 自检 / 手动取消时能安全中断并交还原调度 |
| A5 | AI 助手互动 | 页面右下角有助手立绘与气泡：规划时进入思考动画，执行时播报进度，点击可对话、可收起 |

## 四、FOV 寻路与地图编辑器（新增）

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| F1 | FOV 视野可视化 | 车头前方 110° / 300 单位视野锥；建筑会遮挡射线，锥形轮廓随之切短；页面实时显示可见节点、识别目标和视野路径 |
| F2 | FOV 感知寻路 | 开启后，FOV 发现占道路障时把最近道路节点加入绕行集合，用可见性 A* 重新规划；近处路障仍交给机械臂；无绕行空间时保留原路线，不能卡死 |
| F3 | FOV 开关 | 页面可开启 / 关闭 FOV 寻路；关闭后回到原有全局 A*，旧调度与 AI 路线行为不受影响 |
| E1 | 自定义地图编辑器 | 页面提供「路障 / 火情 / 行人 / 删除」工具，点击地图即可放置或删除；后端校验坐标、数量与对象距离，状态实时同步 |
| E2 | 编辑内容与旧功能兼容 | 新增火情沿用火情自检与灭火流程；新增行人绑定人行道图并遵守红绿灯；路障可被 FOV 绕行或被机械臂清理；清空动态对象不删除默认行人 |

## 五、工程要求

- 以 Python 为主：后端 FastAPI + 原生 JavaScript 页面；
- 沿用现有脚手架结构，新增 `algo/fov.py`、`sim/city.py`，改写 `sim/world.py`、`main.py`、`static/index.html`、测试；
- 所有改动只发生在项目文件夹内；
- 页面图形使用系统 emoji / 公开参考，不自行绘制角色形象；
- 测试覆盖正常流程、边界与失败路径；提交信息使用 `type(scope): 简短中文说明`。
